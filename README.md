Sweet Crumbs Bakery – README
Website Description
Sweet Crumbs Bakery is a simple bakery website created using HTML and external CSS. It provides information about the bakery, its products, and contact details.
Website Pages
•	Home – Introduction to the bakery.
•	About – Information about Sweet Crumbs Bakery.
•	Products – Bakery products offered.
•	Enquiry – Customer enquiry form.
•	Contact – Contact information.
Technologies Used
•	HTML5
•	CSS3 (External Styling)
File Structure
Sweet Crumbs Bakery/
├── index.html
├── about.html
├── products.html
├── enquiry.html
├── contact.html
└── style.css
The style.css file is linked to the HTML pages using:
<link rel="stylesheet" href="style.css">
All files should be kept in the correct folder so that the external styling works properly.
